# Security

AIL links carry text that ends up in someone's AI assistant, so security reports are taken seriously.

## What to report

- A way for a manifest to hide content from the person (the spec requires "visible = sent").
- A way for a conforming consumer to send a message without the person seeing it first.
- A problem in the reference library, such as an invisible character that `lib/hidden.ts` misses.

## How to report

Use **Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting). Please don't open a public issue for an unfixed problem.

Vulnerabilities in ChatGPT, Claude or Gemini themselves should go to those providers. If one affects how AIL consumers should behave, tell us too.
