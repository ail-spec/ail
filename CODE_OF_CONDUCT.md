# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment and personal attacks are not accepted.

To report a problem, contact the maintainers privately through the repository's **Security → Report a vulnerability** form or by messaging a maintainer on GitHub. Reports are handled confidentially.
